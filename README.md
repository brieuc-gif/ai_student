Il s'agit de mon premier projet d'analyse de données, réalisé dans le but de mettre en pratique les compétences que j'ai développées en autodidacte sur SQL, Python (Pandas) et Power BI.

J'ai choisi de travailler sur une base de données accessible portant sur l'utilisation de l'intelligence artificielle par des étudiants afin d'explorer plusieurs questions liées à leurs habitudes de travail, leurs résultats académiques et leur bien-être.

L'objectif de ce projet était de reproduire les différentes étapes d'un processus d'analyse de données :
-Nettoyage des données avec la bibliothèque pandas
-Analyse à l'aide de requêtes SQL 
-Visualisation des résultats avec Power BI

Plusieurs thématiques ont été étudiées, notamment :

Le lien entre l'utilisation de l'IA et les résultats académiques ;
Les différences selon les filières d'études ;
Les habitudes de travail des étudiants ;
Les indicateurs de stress, d'anxiété et de risque de burnout.
Outils utilisés
SQL : exploration et analyse des données ;
Python (Pandas) : préparation et manipulation des données ;
Power BI : création des tableaux de bord et visualisation des résultats.
Compétences mobilisées
Analyse exploratoire de données (EDA) ;
Requêtes SQL (agrégations, sous-requêtes, conditions) ;
Nettoyage et manipulation de données avec Pandas ;
Data visualisation avec Power BI ;
Interprétation et communication des résultats.
Ce projet m'a permis de mettre en pratique les bases de l'analyse de données sur un cas concret et de me familiariser avec l'utilisation conjointe de SQL, Python et Power BI dans un même workflow.

Les résultats présentés doivent être considérés comme des observations exploratoires et non comme des conclusions scientifiques. L'objectif principal était avant tout de développer mes compétences techniques et ma démarche analytique.
